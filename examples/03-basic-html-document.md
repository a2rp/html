# Example 03 - The basic HTML document

## Question

What is the smallest clear structure to start a new HTML page?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>The basic HTML document</title>
</head>
<body>
  <h1>My first page</h1>
  <p>This is a complete HTML document.</p>
</body>
</html>
~~~

## Expected output

The page shows a heading and a paragraph. The browser tab shows the document title.

## Explanation

The doctype comes first. The html element contains head and body. Document information such as the title belongs in head, while reader-facing content belongs in body.
