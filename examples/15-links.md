# Example 15 - Links and the anchor element

## Question

How can you create a useful link to another website?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Links and the anchor element</title>
</head>
<body>
  <main>
    <h1>Useful links</h1>
    <p><a href="https://example.com/">Visit the example site</a></p>
    <p><a href="mailto:hello@example.com">Email the garden team</a></p>
  </main>
</body>
</html>
~~~

## Expected output

The page shows two descriptive links. Selecting the first opens the example site; selecting the second starts an email to the listed address if a mail app is configured.

## Explanation

The anchor element creates a link when it has an href destination. Descriptive link text tells readers where a link goes or what it does.
