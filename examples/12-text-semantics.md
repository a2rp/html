# Example 12 - Text semantics: emphasis, importance, and meaning

## Question

How can markup show emphasis, importance, and highlighted text?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Text semantics: emphasis, importance, and meaning</title>
</head>
<body>
  <main>
    <h1>Text with meaning</h1>
    <p>Please <em>read this carefully</em>.</p>
    <p><strong>Warning:</strong> Save your work before closing.</p>
    <p>The meeting is on <mark>Friday</mark>.</p>
  </main>
</body>
</html>
~~~

## Expected output

The page shows three sentences. Emphasis, importance, and highlighted text have distinct default appearances and meanings.

## Explanation

em marks stress emphasis, strong marks importance, and mark highlights text relevant to the current context. Choose elements for their meaning, not just their appearance.
