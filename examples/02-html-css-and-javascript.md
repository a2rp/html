# Example 02 - How HTML fits into a web page

## Question

Which parts of a simple page can HTML describe on its own?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>How HTML fits into a web page</title>
</head>
<body>
  <main>
    <h1>Three parts of a web page</h1>
    <p>HTML describes the content and its structure.</p>
    <p>CSS can control visual presentation.</p>
    <p>JavaScript can add behavior.</p>
  </main>
</body>
</html>
~~~

## Expected output

A heading and three paragraphs appear. The browser applies its built-in styles, and these elements need no script to display.

## Explanation

This file contains HTML only. HTML supplies structure and meaning. CSS and JavaScript are separate technologies that can be connected to a document when needed.
