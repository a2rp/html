# Example 11 - Headings and paragraphs

## Question

How can headings organize a short article into sections?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Headings and paragraphs</title>
</head>
<body>
  <main>
    <h1>Garden notes</h1>
    <p>These notes describe a small garden.</p>
    <h2>Choosing a place</h2>
    <p>Look for a spot with enough light.</p>
    <h2>Watering</h2>
    <p>Check the soil before adding water.</p>
  </main>
</body>
</html>
~~~

## Expected output

The page shows one main heading, two section headings, and a paragraph beneath each heading.

## Explanation

Use heading levels to describe the document outline. Paragraphs group related sentences. Choose headings for structure and meaning rather than for their default size.
