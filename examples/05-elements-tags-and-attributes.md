# Example 05 - Elements, tags, and attributes

## Question

How can an element use attributes to describe a link?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Elements, tags, and attributes</title>
</head>
<body>
  <main>
    <h1>Elements and attributes</h1>
    <p id="welcome" class="intro">This paragraph has an id and a class.</p>
    <a href="https://example.com">Visit the example site</a>
  </main>
</body>
</html>
~~~

## Expected output

A heading, paragraph, and clickable link appear. The id and class do not add visible text by themselves.

## Explanation

Tags mark the beginning and end of many elements. Attributes such as id, class, and href provide extra information in the start tag.
