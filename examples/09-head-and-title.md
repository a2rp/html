# Example 09 - The head element and page title

## Question

Where do the page title and visible page heading belong?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Garden journal</title>
</head>
<body>
  <h1>Visible page heading</h1>
  <p>The title is shown in the browser tab.</p>
</body>
</html>
~~~

## Expected output

The h1 and paragraph appear in the page. The browser tab shows 'Garden journal'.

## Explanation

The title element belongs in head and names the document outside the page content. The h1 belongs in body and introduces the visible content.
