# Example 01 - Introduction to HTML

## Question

How can you write the structure and meaning of a simple page?

## HTML code

~~~html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Introduction to HTML</title>
</head>
<body>
  <main>
    <h1>Welcome to HTML</h1>
    <p>HTML gives this page its structure and meaning.</p>
  </main>
</body>
</html>
~~~

## Expected output

The browser shows a main page area with a large heading followed by one paragraph.

## Explanation

The h1 introduces the page. The p element marks a paragraph. The main element identifies the page's primary content.
