# HTML

## Introduction

HTML stands for **HyperText Markup Language**. It is the standard markup language used to describe the structure and meaning of content on web pages. A browser reads an HTML document and displays it as a page.

HTML uses elements to identify content such as headings, paragraphs, links, and images. Elements are written with tags and can be nested to organize a document. HTML defines page structure; CSS is used for presentation, and JavaScript is used for behavior.

Here is a small HTML document:

    <!doctype html>
    <html lang="en">
      <head>
        <meta charset="utf-8">
        <title>My first page</title>
      </head>
      <body>
        <h1>Hello, HTML!</h1>
        <p>This is a web page.</p>
      </body>
    </html>

The document type declaration tells the browser to use modern HTML. The head contains information about the document, while the body contains the page content.
